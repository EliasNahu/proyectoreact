# A Gabarda E-commerce 

Este proyecto basa en una tienda de ropa unisex , el cual contiene los stock de la tienda y un carrito con la opcion de compra 


## Tecnologias utilizadas 
 *React.JS 
 *JavaScript
 *HTML5 y CCS3

## Instrucciones de ejecucion

```BASH
    npm install
    npm run dev
```
*ctrl + C , para detener la terminal*
